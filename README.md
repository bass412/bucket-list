# bucket-list
Bass 的人生清单 电影里的两个人，把一生没来得及做的事写在一张纸上，然后一件件去做。 我也想给自己列一份——不是等一个"来不及"的时刻，而是提醒自己：想做的事，别总说"以后"。  三条我信的（而不是喊的）：  把"总有一天"，改写成"今年，我就"。 生命的长度不由我定，但它的宽度，可以。 清单的意义，不在于全部勾完，而在于——我开始动身。

## 管理清单

清单页面从 `items.json` 读取公开条目。点击 [编辑清单](https://github.com/bass412/bucket-list/edit/main/items.json)，登录 GitHub 后可新增、修改或删除内容，然后选择 **Commit changes** 保存。

空列表写作 `[]`。例如，添加两条内容时可以写成：

```json
[
  { "title": "学会烘焙", "category": "美食", "done": false },
  { "title": "学习泰拳或格斗", "category": "运动", "done": false }
]
```

把 `done` 改为 `true` 可标记完成；多个条目之间用逗号分隔。网页中的进度和分类会随文件更新。此仓库是公开的，仅添加愿意公开的内容。
